# Estructura del kit

- [ORCHESTRATOR.md](ORCHESTRATOR.md): responsabilidades del coordinador.
- [PROTOCOL.md](PROTOCOL.md): crear, reutilizar, delegar, revisar y cerrar.
- [LEARNING.md](LEARNING.md): evidencia, pruebas, versionado y reversión.
- [REGISTRY.md](REGISTRY.md): registro público vacío.
- [IA_TEMPLATE/](IA_TEMPLATE/): plantilla genérica para una copia de trabajo autorizada.
- [../ME/](../ME/): plantillas de contexto y referencias de skills.
- [../Agentes/](../Agentes/): ubicación convencional de definiciones, sin agentes creados en este starter.

La fuente operativa es PROTOCOL. Los archivos de entrada y la skill de orquestación remiten a ella para evitar reglas contradictorias. El arranque está en [../BOOTSTRAP.md](../BOOTSTRAP.md).

- [MEMORY.md](MEMORY.md): memorias en archivos y configuración análoga por agente; separación de contexto, no de permisos o MCP.
