# Orquestar agentes

Aplicar [el protocolo canónico](../../../../SYSTEM/PROTOCOL.md), las responsabilidades del [coordinador](../../../../SYSTEM/ORCHESTRATOR.md) y el [ciclo de mejora](../../../../SYSTEM/LEARNING.md).

Antes de crear, comprobar si existe una definición compatible. Usar herramientas nativas para delegar cuando estén disponibles; sin ellas, no simular agentes independientes. El coordinador revisa e integra el resultado y puede resolver tareas simples.

El starter público conserva plantillas y registro vacío. Crear y personalizar únicamente en un destino autorizado; nunca publicar datos personales como parte del arranque. No instalar skills ni ampliar permisos por leer esta guía.
